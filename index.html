Paper of the Week
8/10 excitement

Random features suddenly become fully trainable, reshaping model scalability paradigm.

Xin He, Huan Lao, Xiliang Lu · math.NA

Problem: Scientific computing still relies on hand‑crafted basis functions or fixed random features, limiting accuracy and adaptability.

Key insight: The authors identify a sharp phase transition where modest trainability of random features yields fully trainable networks, backed by theory and empirical scaling laws.

Why practitioners care: It explains when cheap random‑feature models can be upgraded to high‑performance nets without redesign, guiding resource allocation for large‑scale simulations.

Key Takeaway

Start with random features and add a small trainable head; expect full network performance beyond the identified transition.
